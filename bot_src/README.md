# 🔥 بوت الأرقام + المتجر — نسخة الأرقام والجلسات والمتجر

نسخة مخصصة لبيع الأرقام (واتساب + تيليجرام OTP + جلسات جاهزة)
+ متجر متكامل: رشق سوشيال + شحن ألعاب + شحن برامج + رصيد سيريتل/MTN.

## ▶️ التشغيل

```bash
cp .env.example .env
# عبّي BOT_TOKEN و ADMIN_IDS و ADMIN_NOTIFY_CHAT_ID ومفتاح مزود أرقام واحد على الأقل
pip install -r requirements.txt
python bot.py
```

## 📱 واجهة الزبون

- 📱 شراء أرقام (`num_hub`)
- قسم ارقام تلجرام جاهزة (`tgready:list`)
- 🛍 المتجر (`store:home`): رشق / ألعاب / برامج / رصيد
- 👤 حسابي | 💰 شحن الرصيد | 🎁 الإحالة | 🆘 الدعم | ℹ️ معلومات البوت

## 🛍 المتجر (جديد)

- **الرشق:** قسم + 8 تطبيقات (انستا/تيك توك/يوتيوب/تيليجرام/فيسبوك/واتساب/سناب/تويتر) عبر لوحة SMM (`smm_v2`).
- **الألعاب/البرامج/الرصيد:** عبر HyperStore — الشجرة تُبنى تلقائياً + الحقول ديناميكية
  (رابط / Player ID / رقم 09) + فئات ثابتة (dropdown سيريتل/MTN).
- التسعير هرمي: منتج ← فرع ← قسم ← عام (`default_profit_margin_percent`).
- الاسترجاع تلقائي عند فشل المزود + متابعة دورية كل دقيقة (`tasks/store_monitor.py`).

### ربط مزودي المتجر (من لوحة الأدمن — بدون .env)

```
/admin ← 🛍 المتجر ← 🔌 مزودو المتجر ← إضافة مزود
- HyperStore: الرابط https://api.hyper4store.com + التوكن
- SMM: رابط لوحة الـ SMM بصيغة /api/v2 + المفتاح
ثم 🩺 فحص + 🔄 مزامنة ← 🌳 إنشاء الأقسام ← 📤 نشر من المزود
```

⚠️ مفاتيح API تُحفظ في قاعدة البيانات فقط — لا ترفعها على git أبداً.

### التجهيز التلقائي للمتجر (بدون لوحة أدمن)

```bash
HYPERSTORE_API_KEY=... SMM_API_KEY=... python scripts/seed_store.py
# MARGIN=50 اختياري — ينشئ المزودين + يزامن + يبني الأقسام + ينشر باقة منقاة
```

### أزرار تجهيز كل قسم (من اللوحة — بهامش خاص لكل قسم)

/admin ← 🛍 المتجر:
- 🎮 تجهيز قسم شحن الألعاب | 📱 التطبيقات | 💳 الأرصدة | 📈 الرشق
- كل زر يعرض النطاق ← تضع نسبة الربح ← يجهز القسم كاملاً (عربي + أسعار + فئات)

## 🔥 أقسام الأرقام

1. **OTP عادي** (`handlers/numbers.py`):
   سيرفرات مرقمة بدون كشف المزود، دول من الأرخص للأغلى،
   فردي + جملة + باقات، ضمان استرجاع 5 دقائق، ملف CSV للدفعات.
2. **جلسات جاهزة** (`handlers/tg_ready.py`):
   مخزون مشفر، تسليم ZIP فوري (session + tdata + 2FA)،
   زر 📩 طلب الكود التلقائي، إعادة إرسال الملف.

## 🌐 المزودون (6)

5sim / HeroSMS / SMS-Activate / SMSHub / SMSPool / GrizzlySMS
عبر `providers/manager.py` مع Failover + سقف سعر + توجيه ذكي + حظر المخزون الوهمي.

## 🛠 لوحة الأدمن

- 🛍 المتجر: مزودو المتجر، أقسام المتجر، نشر من المزود، إنشاء تلقائي للشجرة والرشق
- 📱 الأرقام والجلسات: خدمات، سيرفرات كل خدمة + هامش كل سيرفر + 🟢 شغال الآن، دول، مزودين، جودة المزودين، أسعار وهوامش، قناة التوفر المتقطع
- 💰 المالية: شحن، جرد، إحصائيات، باقات نجوم
- 👥 المستخدمون: مستخدمين، إذاعة، اشتراك إجباري، تذاكر، إشعارات
- ⚙️ النظام: صحة، إعدادات، صيانة، أزرار الواجهة، مباشر البوت، أدمنية، سجل

## 📱 تجهيز الأرقام (HeroSMS + GrizzlySMS)

سيرفر واحد لكل مزود داخل قسمي واتساب وتيليجرام + سحب الدول مع التعريب + الهوامش:

```bash
HEROSMS_API_KEY=... GRIZZLY_API_KEY=... python scripts/seed_numbers.py
# (تُقرأ من .env تلقائياً إن وُجدت فيه — MARGIN=50 اختياري)
```

## قسم ارقام تلجرام جاهزة (TgReady)

الرفع من اللوحة: `/admin` ← قسم ارقام تلجرام جاهزة ← 📤 رفع ملف (txt/csv/zip بصيغة المورّد).
الهامش يُضبط تلقائياً من سكربت الأرقام ويمكن تغييره من اللوحة.

## ✨ الميزات المتقدمة

- 🎟 **كوبونات وحملات**: `/admin` ← المستخدمون ← الكوبونات (نسبة/مبلغ + حدود + مصدر) — تُستخدم بشاشة تأكيد المتجر
- 🧺 **السلة**: إضافة من شاشة التأكيد + إتمام جماعي بدفعة واحدة
- 💱 **تحويل الرصيد**: من 👤 حسابي — بعمولة وحد أدنى من الإعدادات
- 📣 **إثبات اجتماعي**: إتمام الطلبات يُنشر بالقناة العامة + تقييمات نجوم على المنتجات
- 🔔 **تنبيهات**: زر «نبهني» بصفحة المنتج + فحص دوري
- 🔥 **عروض مؤقتة**: من صفحة المنتج باللوحة (خصم + مدة) + عدّاد + قائمة بالمتجر
- 🔁 **احتراف الرشق**: إعادة تعبئة Refill + إعادة طلب بضغطة + تتبع التقدم
- 👑 **خصم التجار**: رتب (عادي/تاجر 5%/ذهبي 10%) — طلب من حسابي + موافقة الأدمن من قناة الإشعارات أو اللوحة — يطبق على المتجر والأرقام
- 🎨 **ستايل Lux**: رسائل بصناديق ━━━ وأسعار مزدوجة $ + ل.س ومدد تنفيذ ورد السيرفر («نورت بوتنا»)
